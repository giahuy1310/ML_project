# ML_project

Starter setup for a machine learning project focused on running experiments in Jupyter notebooks.

## Project structure

```text
ML_project/
├── notebooks/
│   └── 01_experiment_template.ipynb
└── requirements.txt
```

## Getting started

1. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start Jupyter:

   ```bash
   jupyter lab
   ```

4. Open `notebooks/01_experiment_template.ipynb` and start experimenting.
